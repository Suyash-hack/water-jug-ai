# 🧠 Water Jug Problem Solver (AI Based)

This project is an implementation of the **Water Jug Problem** using Artificial Intelligence concepts.  
It finds the sequence of steps required to measure a target amount of water using two jugs of given capacities.

The project is built using:

- ⚛️ React (Frontend)
- 🐍 Django (Backend)
- 🔗 REST API Integration

---

## 🚀 Features

- Input jug capacities and target value
- Uses AI search algorithm (BFS)
- Displays step-by-step solution
- Clean React UI
- Django REST backend

---

## 🛠️ Technologies Used

### Frontend
- React JS
- Axios
- HTML / CSS

### Backend
- Django
- Django REST Framework
- CORS Headers
